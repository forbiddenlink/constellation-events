## 🎯 What It Does

Constellation Events is a full-stack event platform where organizers can create and manage events while attendees can discover and register. Clean, modern UI built with Next.js and TypeScript.

## ✨ Features

- 📅 Create and manage events with rich details
- 🔍 Discover events by category, date, and location
- 🎟️ Registration and RSVP system
- 📱 Mobile-first responsive design

## 🚀 Getting Started

```bash
git clone https://github.com/forbiddenlink/constellation-events
cd constellation-events
npm install
cp .env.example .env.local  # configure your environment
npm run dev
```

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
